# 🚁 Zeewolf for Android — Classic Amiga Helicopter Combat APK

[← Game collection](../../README.md) · [APK installation](../INSTALLATION.md) · [GitHub Releases](https://github.com/Andiweli/Amiga-Android-GameCollection/releases)

**Zeewolf (1994)** is a 3D helicopter action game for the **Commodore Amiga**, originally developed by **Binary Asylum** and published by **Empire Software**. This unofficial dedicated Android adaptation adds modern controller input, a touchscreen interface, save states and configurable performance.

## ✨ Android features

- Standalone APK with its own Android launcher icon and settings
- Left-stick / D-pad helicopter movement and **right-stick mouse aiming**
- Customizable controller button mapping and mouse sensitivity
- On-screen touch controls for devices without gamepads
- Save/load states and optional resume
- Audio and video settings including image smoothing and CRT scanlines
- Optional gameplay assists for cannon, rockets, air-to-air missiles, fuel and health
- Adjustable speed presets to change game responsiveness

## 🎮 Default controller mapping

| Input | Action |
| --- | --- |
| Left analog stick / D-pad | Helicopter movement and menu navigation |
| Right analog stick | Mouse-style aiming |
| **A** or **R2** | Fire |
| **B** or **R1** | Switch weapon |
| **X** or **L3** | Map / Enter |
| **Y** | Hook |
| **L1** | Landing gear |
| **Start** | Pause |
| **Select (hold ~1 second)** | Open Android app menu |
| **R3** | Abort / Escape |

You can customize the mapped buttons through the Android menu.

## ⚡ Frame-rate and performance modes

The app's menu offers three game-specific presets:

| Mode | Stated game picture rate |
| --- | --- |
| **Original A500** | Approximately **7 fps** |
| **Fast Amiga** | Up to **17 fps** |
| **Turbo** | Up to **25 fps** |

These are **app presets and approximate in-game picture rates**, not benchmark results or promises for every Android device.

## 💿 Zeewolf ADF requirements

The app imports **one** compatible, uncompressed **901,120-byte (880 KiB) AmigaDOS ADF**. Its importer checks for the expected Zeewolf disk layout, including the `STARTUP 68K` and `WOLFNEW DAT` entries.

The original Amiga game image is **not included** with the APK. Use your own lawfully obtained compatible ADF; no separate Kickstart ROM is required.

## 📱 Android installation and compatibility

The supplied Android Studio project specifies **Android 7.0 or newer**, with **64-bit ARM64 or x86_64 binaries** and landscape orientation. Individual compatibility depends on the device and controller.
