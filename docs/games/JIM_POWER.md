# 🚀 Jim Power in Mutant Planet for Android — Amiga Platform Shooter APK

[← Game collection](../../README.md) · [APK installation](../INSTALLATION.md) · [GitHub Releases](https://github.com/Andiweli/Amiga-Android-GameCollection/releases)

Play **Jim Power in Mutant Planet (1992)**, the classic **Commodore Amiga side-scrolling action platformer**, with a dedicated Android APK and a built-in, game-specific Amiga emulation runtime. Originally associated with **Loriciel / Digital Concept**, the game combines jumping, shooting and sci-fi platform action.

## ✨ Android adaptation features

- Individual Android app, launcher icon and settings menu
- Customizable controller buttons and on-screen touch controls
- Game movement, jump, duck, fire and autofire inputs
- Save/load states and optional resume
- Image scaling, smoothing, CRT scanlines and audio options
- Optional gameplay assists for lives, smart bombs and keys

The original commercial game disks, graphics and music are **not included** in the APK download.

## 🎮 Default gamepad controls

| Input | Action |
| --- | --- |
| Left analog stick / D-pad | Move; up to jump, down to duck |
| **A**, **Y** or **R2** | Fire |
| **B** or **L1** | Jump |
| **X** or **R1** | Autofire |
| **Start** | Pause |
| **Select (hold ~1 second)** | Open Android app menu |
| **R3** | Abort / Escape |

**Tip:** Holding fire can charge a smart bomb in the supported game implementation. Controller assignments may be remapped to suit the device.

## 💿 ADF requirements — both Amiga floppy disks

The Android importer requires **two separate, compatible, uncompressed 901,120-byte (880 KiB) Amiga ADF files**. Select disk 1 and disk 2 in the requested order. You must supply your **own legally obtained** disk images.

WHDLoad packages, compressed archives and other formats are not directly equivalent to the two supported ADF disk images. No additional Kickstart ROM is required.

## 📱 Android compatibility and installation

The Android Studio project specifies **Android 7.0 (API 24) or newer**, with **`arm64-v8a` and `x86_64`** support. Actual device support and controller behavior may vary. See the [installation and troubleshooting guide](../INSTALLATION.md).
